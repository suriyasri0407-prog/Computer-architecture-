Debug Part

1. Signed Addition: Debug overflow by checking the overflow flag when the result is outside the allowed range.


2. Ripple Carry Adder: Debug the slow addition by replacing it with a faster Carry Look-Ahead Adder.


3. Booth Multiplication: Debug by checking the bits, sign, and arithmetic right shift correctly.


4. Restoring Division: Debug the slow process by using Non-Restoring Division.


5. IEEE 754 Addition: Debug floating-point errors by checking exponent alignment, rounding, and precision.
